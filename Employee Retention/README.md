# 📊 Employee Attrition & Salary Analysis

## 📝 Overview

This workbook contains an **Employee Attrition Data** dataset designed for practical Excel-based analysis of employee information, salary patterns, departmental distribution, attrition, experience levels, and retention incentives.

The workbook also includes a set of **business questions** and **Excel interview questions** to support analytical practice and demonstrate the use of common Excel functions.

---

## 📁 Workbook Structure

The workbook is organized into three worksheets:

| Worksheet | Purpose |
|---|---|
| 👥 **Employee** | Contains employee-level information, calculated classifications, salary analysis, and summary results |
| 💼 **Business Questions** | Contains business-oriented questions based on the employee dataset |
| 🎯 **Interview Questions** | Contains Excel-related interview questions and the relevant formulas/functions |

---

## 👥 Employee Data

The **Employee** worksheet contains records for **20 employees** with the following fields:

- 🆔 **EmpID** — Unique employee identifier
- 👤 **Name** — Employee name
- 🏢 **Department** — Employee's department
- ⚥ **Gender** — Employee gender
- 📅 **Experience** — Years of professional experience
- 💰 **Salary** — Employee salary
- 🚪 **Attrition** — Indicates whether the employee left the company
- ⭐ **Senior/Junior** — Employee classification based on experience
- 💵 **High Salary/Low Salary** — Salary classification
- 🎁 **10% Retention Bonus** — Bonus calculated according to the salary condition
- 🔤 **Proper Case** — Employee name formatted in proper case
- ✂️ **Extract 2 Letters** — First two letters extracted from the employee name

- Identification of employees with more than 5 years of experience
- Classification of employees as **Senior** or **Junior**
- Identification of employees earning above ₹50,000

The worksheet calculates a **10% retention bonus** for employees earning more than ₹60,000, supporting a simple employee-retention analysis.

The workbook demonstrates:
- Converting employee names into **Proper Case**
- Extracting the **first two letters** from employee names

## 🧮 Excel Functions Demonstrated

The workbook provides practical examples of commonly used Excel functions:

| Function | Use Case |
|---|---|
| `SUM()` | Calculate total salary |
| `AVERAGE()` | Calculate average salary |
| `MAX()` | Find the highest salary |
| `MIN()` | Find the lowest salary |
| `COUNT()` | Count employee records |
| `COUNTIF()` | Count employees meeting a condition |
| `SUMIF()` | Calculate salary totals based on department |
| `AVERAGEIF()` | Calculate average salary based on a condition |
| `IF()` | Create salary and experience classifications |
| `PROPER()` | Convert names into proper case |
| `LEFT()` | Extract the first two characters of a name |
